# Android 手机 WiFi MVP 真机测试手册

## 测试对象

- Android APP：`0.3.0`（`versionCode 3`）
- 包名：`com.vokie.phone`
- APK：`app/build/outputs/apk/debug/app-debug.apk`
- 连接方式：同一局域网内 mDNS/DNS-SD + TCP 长连接
- 服务类型：`_vokie-phone._tcp`
- 音频：PCM16、16 kHz、单声道、20 ms

此版本是局域网开发验证包。它已实现双方 6 位验证码、PC 配对批准和长期设备令牌认证，
但链路尚未实现 TLS 和 PC 证书 pin，不能作为正式发布包，也不能在不可信局域网使用。

## 安装与前置条件

1. PC 和手机连接同一 WiFi，PC 运行当前仓库共享 Dev。
2. 执行 `adb install -r app/build/outputs/apk/debug/app-debug.apk`。
3. 在手机系统界面批准麦克风和附近 WiFi 设备权限。
4. 启动 `com.vokie.phone/.MainActivity`。

OPPO 系统不要使用 `adb install -r -g`；该系统会拒绝 shell 直接授予运行时权限。安装确认和
权限确认均在手机系统界面完成。

## 必测用例

| 用例        | 操作                            | 预期                                     |
| ----------- | ------------------------------- | ---------------------------------------- |
| 首次配对    | 首次选择发现的 Vokie            | 双端只弹一次且显示相同的 6 位验证码      |
| 批准连接    | 在 PC 点击“允许连接”            | 手机关闭验证码弹窗并变为“已连接”         |
| 自动认证    | 关闭并重新打开手机 APP          | 不再弹配对确认，自动变为“已连接”         |
| 自动发现    | 启动 PC Vokie 后打开手机 APP    | 自动发现同一 WiFi 的 Vokie，无需蓝牙     |
| PC 名称     | 查看手机顶部及 Vokie 列表       | 显示系统电脑名称，无 `.local` 数字后缀   |
| 更多菜单    | 点击顶部三点按钮                | 显示 Vokie 列表、录音模式和设备管理      |
| 免提模式    | 点击开始，说话后再次点击停止    | PC 进入 Handsfree 会话并接收手机 PCM     |
| 长录音模式  | 点击开始，说话后再次点击停止    | PC 生成 Toggle 录音、音频和转写记录      |
| PC 停止录音 | 手机开始免提/长录音后在 PC 结束 | 手机同步停止采集、通知和水波，不重复提交 |
| 选择设备    | 列表中选择设备并点击确认加入    | 连接所选设备；取消时保持原连接           |
| 断开设备    | 菜单点击“断开当前设备”          | 当前连接释放，长期凭据保留并显示重新连接 |
| 手动重连    | 断开后点击底部“重新连接”        | 不重启发现服务，直接恢复当前设备连接     |
| PC 端断开   | 在 PC 手机卡片点击“断开”        | WiFi socket 关闭，手机等待手动重新连接   |
| 解除验证    | 确认解除当前设备验证            | 双端删除凭据，再次加入重新显示验证码     |
| 单页布局    | 检查主界面并尝试上下滑动        | 所有按钮位于首屏，页面不产生滚动         |
| APP 图标    | 查看桌面和系统应用详情          | 显示 Vokie 声波图标，圆形裁切完整清晰    |
| 发送        | 点击底部“发送”                  | PC 执行一次发送/Enter                    |
| 撤回        | 点击底部“撤回”                  | PC 撤回最近一次 Vokie 输出               |
| 状态反馈    | 点击发送、撤回或唤起 Vokie      | 短暂提示后自动恢复“已连接”               |
| 唤起 Vokie  | 点击“唤起 Vokie”                | 已运行的 Vokie 主窗口显示并置前          |
| 录音水波纹  | 开始录音并改变说话音量          | 音量越大扩散稍快且更亮，无抖动或位置跳变 |
| 后台录音    | 免提或长录音开始后返回桌面      | 持续通知存在，PC 持续收到 PCM            |
| 锁屏录音    | 长录音开始后关闭手机屏幕        | CPU/WiFi 保持工作，录音不中断            |
| 通知停止    | 后台录音时点击通知“停止录音”    | 正常发送结束事件并释放通知和系统锁       |
| 语音输入    | 按住蓝色麦克风说话，松开        | PC 收到 PCM，ASR 完成并输出文本          |
| 自动提交    | 正常语音识别完成                | 沿用 PC 设置发送一次 Enter，不重复发送   |
| 自动重连    | 重启共享 Dev                    | 服务恢复后手机自动发现并回到“已连接”     |
| 离线退避    | 停止 PC Vokie 并观察连接请求    | TCP 重试逐步降至每 30 秒；服务消失即停   |
| 发现恢复    | PC 离线后以同名服务重新启动     | 最迟 30 秒刷新发现并自动恢复连接         |
| 权限拒绝    | 撤销麦克风权限后按住            | 不录音、不崩溃，并引导重新授权           |
| 断网        | 录音前关闭手机 WiFi             | 状态离线，不允许开始录音                 |
| 恢复网络    | 重新加入同一 WiFi               | 重新发现并连接 PC                        |
